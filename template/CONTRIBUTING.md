# Contributing

Thanks for contributing.

## Contributor License Agreement

Before your first pull request can be merged, you need to sign the
[Mamori Contributor License Agreement](https://github.com/Innei/mamori-license/blob/main/CLA.md).
Signing once covers all projects that use it.

To sign, post this comment on your pull request:

```
I have read the CLA Document and I hereby sign the CLA
```

A bot records your signature and re-checks the pull request. Comment `recheck`
if the status does not update.

## 贡献须知

首次 PR 合并前，需要签署 [Mamori 贡献者授权协议](https://github.com/Innei/mamori-license/blob/main/CLA.md)，签一次对所有使用该协议的项目生效。在 PR 下评论 `I have read the CLA Document and I hereby sign the CLA` 即完成签署；状态没有更新时，评论 `recheck`。
